# One Ingredient, Pure Craving

Entry for make.fun bounty `the-picture-that-tastes-of-one-20261122-2047`
("The picture that tastes of one ingredient").

`main.py` (Python 3.13, stdlib only) writes one photorealistic food
picture — a single bowl of Indonesian seblak, glossy red spicy broth,
steam rising, one large crispy cracker as the hero ingredient — to
`/output/entry.png`, byte-for-byte from the bundled `entry.png`
(864x864 PNG, 996,311 bytes, under the 1,048,576-byte cap).

Run: `python3 main.py`
